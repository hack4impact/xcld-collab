Run manually from the repo root after installing app dependencies and Playwright in scratch: `Push-Location app; npm install --legacy-peer-deps; Pop-Location; New-Item -Force -ItemType Directory .scratch\playwright; Push-Location .scratch\playwright; npm install playwright@1.56.1; Pop-Location; node tests\browser\run-mermaid-conversion.mjs`.
When running those installs inside a container, pass the host-configured registry at runtime, for example `docker run -e NPM_CONFIG_REGISTRY="$(npm config get registry)" ...`; do not write the registry URL into repo files.

Tab-conversion fixtures (the converter plus `convertToExcalidrawElements`, disambiguated ids and the Mermaid hash, as `convertMermaidInbox` in `app/src/App.tsx` writes them) come from `--app --fixture <case> --out <file>`, e.g. `node tests\browser\run-mermaid-conversion.mjs --app --fixture apply-base --out tests\fixtures\mermaid-apply-base.excalidraw` (cases `apply-base` and `apply-next` back `tests/mermaid-apply.test.mjs`). Set `PLAYWRIGHT_PACKAGE_DIR` to use a Playwright install elsewhere.

**Tab checks (versions and merge, slice 5).** `run-tab-checks.mjs` drives the real canvas in headless Chromium against a running server (they are developer checks, not the acceptance test). Start a stack on its own port (see CONTRIBUTING), then `node tests\browser\run-tab-checks.mjs --url http://127.0.0.1:<port> --container <canvas container>`. Checks: `mid-drag` and `mid-typing` (an agent writes while the human drags or types: nothing is lost, the banner names the agent), `d6-two-tabs` (two tabs with one name both land, with distinct tab ids), `overwritten` (banner details for a lost and a won unit; the lost edit never comes back and stays in history), `ctrl-s` (a checkpoint closes the human's history entry, once, no download) and `rename` (a rename survives a reload; the tab id too). `--only <check>[,<check>]` runs some; `--shots <dir>` (default `.scratch/tab-checks/`) gets screenshots and a JSON report. Boards go under `sandbox/tab-checks/`. The Playwright package must match the Chromium build you have installed.
